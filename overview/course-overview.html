Why you read before class

We meet 150 minutes a week. Reading the unit aloud would use all of it, and you would still not have written anything.

Class time is for the part that does not work alone: building something with a real decision in it, and arguing about it.

Using AI

Every assignment carries a level. Most of this course is Level 1: ask an AI to explain a concept, never to write code you submit.

Sprints and the project are Level 2: it may look at code you already wrote and tell you what is wrong with it.

You may be asked to explain your own work. That is the whole enforcement mechanism.
