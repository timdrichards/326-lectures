10:00phase 1

flex-wrap is the whole trick

Flexbox alone puts everything in one row.


.entries {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

Padding, border, and box-sizing

Padding and a border both add to an element's visible size, unless box-sizing: border-box says otherwise.


.card {
  padding: 1rem;
  border: 1px solid var(--color-border);
  box-sizing: border-box;
}

One variable, used everywhere

A CSS custom property defined once, referenced everywhere.


:root {
  --color-border: #ccc;
}

.card { border-color: var(--color-border); }

Activity: Where Does It Stack?

Style a small card layout of your own (three or four cards, any content) with flexbox and at least one CSS custom property.

Decide together: on a narrow, phone-width screen, do your cards stack to one column, or stay two? Pick a real breakpoint and be able to say why there and not somewhere else.
