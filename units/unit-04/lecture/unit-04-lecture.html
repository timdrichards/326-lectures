Selectors and the cascade

Three ways to say which elements you mean.


body { }        /* type: every <body> */
nav a { }       /* descendant: <a> inside <nav> */
.site-header { }  /* class: anything with that class */

When two rules fight, specificity decides: id beats class beats type.

The box model

Every element is four nested boxes.


content  ->  padding  ->  border  ->  margin

* { box-sizing: border-box; }

Padding is inside the border, margin is outside it. By default a 300px box with 20px padding occupies 340px.

Layout with flexbox

The box model controls one element. Flexbox controls how siblings share space.


.site-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

How style.css Reaches the Page

Two requests, not one.


<!-- views/entries.ejs -->
<link rel="stylesheet" href="/style.css">

// server.js
app.use(express.static('public'));

// the browser asks:  GET /style.css
// Express sends:     public/style.css

The page arrives first and names its stylesheet. The browser then asks for it separately. Without the static line that second request 404s, which is Q2. The href is a URL, not a path on your disk.

What flex: 1 1 200px Says


li {
  flex: 1 1 200px;  /* grow, shrink, basis */
}

Every card starts at 200px, however much text it holds.

Room left over? Grow shares it equally, since every card has a grow of 1.

Not enough room? Shrink takes it back. With flex-wrap, a card that cannot fit at 200px plus the gap moves to the next line instead.

Three Small Ones

gap or margin? gap belongs to the flex container and only goes between items. A margin belongs to one item and applies at the edges too. For a row of cards, use gap.

rem or px? 1rem is the root font size, which is 16px only by default. Raise the browser's default text size and rem grows with it; px does not.

What is nav a? Every a inside a nav, here the header links. .site-header is the same idea by class: the header in partials/header.ejs.

flex-wrap is the whole trick

Flexbox alone puts everything in one row.


ul {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  list-style: none;
  padding: 0;
}

Padding, border, and box-sizing

Padding and a border both add to an element's width, unless you say otherwise.


* {
  box-sizing: border-box;
}

li {
  flex: 1 1 200px;
  padding: 0.75rem;
  border: 1px solid #ddd;
}

One variable, used everywhere

A custom property defined once, referenced everywhere.


:root {
  --color-border: #ccc;
  --spacing-md: 1rem;
}

li {
  border: 1px solid var(--color-border);
  padding: var(--spacing-md);
}

Activity: Where Does It Stack?

Style a small card layout of your own (three or four cards, any content) with flexbox and at least one CSS custom property.

Decide together: on a narrow, phone-width screen, do your cards stack to one column, or stay two? Pick a real breakpoint and be able to say why there and not somewhere else.

The full brief and starter code are in Canvas, under this unit. Nothing is submitted.

Compare and Share Back

Compare your breakpoint with a neighbouring group. Resize both to the same width and see whose choice actually looks better at that exact size.

Now, not before. About five minutes.
